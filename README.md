# mattysen english

Сайт для изучения американского английского: больше 3000 слов от A1 до C1 с историей выученных (внутри раздела «Карточки»), тесты по 12 темам, раздел IELTS / SAT / TOEFL, грамматика по разделам, карта университетов США с избранным и план занятий под ваше время.

Сборка не нужна: это обычные HTML, CSS и JavaScript.

## Структура

```
index.html            главная
pages/
  cards.html          карточки слов и история (выученные и запомненные)
  quiz.html           мини-тесты по темам
  exams.html          IELTS, SAT, TOEFL
  grammar.html        грамматика (разделы открываются как grammar.html#tenses)
  map.html            карта университетов США с избранным
  plan.html           план занятий
css/
  style.css           все стили
js/
  common.js           тема, хранилище слов, случайная выборка заданий, меню
  home.js             слово дня
  cards.js            карточки и история
  quiz.js             мини-тесты по темам
  exams.js            разминка по экзаменам
  grammar.js          вывод разделов грамматики
  map.js              карта и список университетов
  plan.js             план занятий
  data/
    words.js              слова с примерами и транскрипцией
    words-a1.js ... words-c1.js   слова по уровням CEFR (A1, A2, B1, B2, C1)
    quiz-questions.js     задания мини-тестов по 12 темам
    exam-questions.js     задания разминки IELTS, SAT, TOEFL
    grammar-sections.js   разделы грамматики
    universities.js       университеты и колледжи США с координатами
```

## Как добавить слово, вопрос или университет

Откройте нужный файл в `js/data/` и допишите строку по образцу соседних.

- Слова по уровням лежат в `words-a1.js` ... `words-c1.js`. Одна строка это одно слово: `английское слово|перевод`.
- Задания мини-тестов в `quiz-questions.js`: `вопрос|вариант 1;вариант 2;вариант 3|номер верного (с единицы)|объяснение`.
- Университеты в `universities.js`: `название|город|штат|широта|долгота|тип|категория|э` (последнее поле «э» ставится у вузов с известной программой по экономики, можно не писать).

## Как выложить на GitHub Pages

1. Создайте на GitHub репозиторий, например `mattysen-english`.
2. Нажмите **Add file → Upload files** и перетащите внутрь **содержимое** папки: `index.html`, `README.md` и папки `pages`, `css`, `js`. Затем **Commit changes**.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`. Нажмите **Save**.
4. Через минуту-две сайт откроется по адресу `https://ВАШ-НИК.github.io/mattysen-english/`.

Выученные слова, свои слова, тема и выбранный план сохраняются в браузере посетителя. Для карты нужен интернет: библиотека Leaflet и подложка OpenStreetMap подгружаются из сети.
