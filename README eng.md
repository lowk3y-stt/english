# lowk3y english

Сайт для изучения американского английского: карточки слов, мини-тест, раздел IELTS / SAT / TOEFL со ссылками на официальные пробные варианты, грамматика и план на неделю.

Это один статический файл, `index.html`. Сборка не нужна.

## Как выложить на GitHub Pages

1. Создайте на GitHub новый репозиторий, например `lowk3y-english`.
2. Нажмите **Add file → Upload files** и загрузите `index.html` и `README.md`. Затем **Commit changes**.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`. Нажмите **Save**.
4. Через минуту-две сайт появится по адресу `https://ВАШ-НИК.github.io/lowk3y-english/`.

Страницы переключаются без перезагрузки: у каждой своя ссылка вида `…/#exams`, `…/#grammar`.
